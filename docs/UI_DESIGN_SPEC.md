# LabelPilot UI 设计规范

版本：0.5（Draft） · 更新：2026-09-20

本文只规定界面视觉、交互与响应式规则。修复进度、验收记录和复用候选见 [UI 维护记录](UI_MAINTENANCE.md)。PDF 排版算法、业务校验和数据结构不在本文范围内。

“必须”表示硬约束；“应”表示默认设计选择，偏离时需说明理由。修改设计规则时同步更新实现与相关测试。

## 1. 设计方向

- 预览优先：纸张是主内容，设置与导航服务于排版和输出。
- 紧凑可读：减少重复摘要和装饰，不牺牲文件识别、输入可读性和命中区。
- 状态明确：选中、聚焦、禁用、生成中和错误有稳定且可辨识的反馈。
- 一致复用：使用语义 token、既定尺寸和公共控件，不堆叠近似样式。
- 按控件类别统一：普通按钮尽量共享样式与状态；输入框内部统一，但不要求与按钮相同。生成、取消、危险操作等特殊按钮允许有明确的语义差异。
- 多种输入方式可用：关键操作不能只依赖悬停或拖拽。

## 2. 布局与响应式

| 范围          | 布局                                                          |
| ------------- | ------------------------------------------------------------- |
| 小于 640px    | 头部仅显示 Logo 图标；预览、底部操作栏与编辑面板              |
| 640–1023px    | 完整品牌字标，仍使用移动编辑面板                              |
| 1024px 及以上 | 左侧 20rem 控制面板，右侧弹性预览；生成操作固定在控制面板底部 |

- 使用动态视口高度，桌面主区内边距 12px、移动端 8px，区域间距 12px。
- 编辑面板默认约 62dvh，可切换全屏；正文独立滚动，标题和底部操作始终可达。
- 控制面板、编辑面板和纸张各自承担滚动，不能撑大应用根容器。flex 高度链允许子项收缩，fieldset 不得破坏滚动链。
- 长文件名和状态文案允许收缩、截断或换行，完整信息通过适当提示或可访问名称保留。
- 安全区只补偿一次；切换至桌面时清理旧移动面板状态。
- 浮动控件互相避让；半透明不能代替布局避让。

## 3. 颜色、字体与尺度

主题和共享样式以 [src/index.css](../src/index.css) 为实现入口，不在组件中复制具体灰阶或亮暗主题分支。

| 用途                          | Token                                  |
| ----------------------------- | -------------------------------------- |
| 工作台 / 普通面板 / 抬升表面  | background / surface / elevated        |
| 主文字 / 辅助文字 / 细边框    | text-main / text-muted / border-subtle |
| 主操作与选中 / 品牌色上的文字 | brand-primary / on-brand               |
| 成功、错误、警告              | 对应状态 token，配合可读文字或图标     |

- 普通面板使用细边框；阴影用于浮层和纸张层次，避免厚边框、渐变和玻璃模糊。
- 纸张中的黑白及输出字体属于打印预览语义，不强行套用 UI 主题色。
- 品牌前景/背景文字组合至少 4.5:1 对比度；半透明效果结合实际背景验收。
- UI 使用 MiSans；数字、单位、百分比、数量与校准值优先使用 Maple Mono。普通中文说明保持无衬线字体，输出预览继续使用相应 PDF 字体。

| 内容          | 字体基线                        |
| ------------- | ------------------------------- |
| 分组标题      | group-title，12px、半粗、弱化色 |
| 字段标签      | 14px、中等字重、弱化色          |
| 正文 / 文件名 | 14px；文件名可半粗              |
| 辅助说明      | 12px、弱化色                    |
| 数值输入      | 14px、等宽、半粗                |
| 主操作        | 14px、粗体                      |

- 常用间距为 6、8、12、16、20px，避免相邻任意值。
- 控件圆角 6px，面板 8px，移动底部面板可用 12px；内圆角不大于外圆角。
- 边框使用 input-base 或 border-subtle，不叠加承担相同职责的 border、ring 与 shadow。

## 4. 控件尺寸与输入

| 控件               | 可见尺寸                            |
| ------------------ | ----------------------------------- |
| 次要图标操作       | 32×32px                             |
| 紧凑导航           | 36×36px                             |
| 移动表单与数量步进 | 高 40px；步进按钮宽 40px，图标 16px |
| 移动主要操作       | 高度至少 44px                       |

- 可见尺寸与命中区分开设计。触控命中目标为 44px；40px 步进控件是已接受的紧凑例外。
- hit-target 扩展不能覆盖相邻按钮或文字，间隙按两侧扩展量计算，并检查祖先裁剪。
- 复合控件按实际尺寸验收：边框不能把预期 40px 的内部按钮挤为 38px，焦点轮廓不得被裁掉。
- 禁用采用原生 disabled，取消 hover/active 反馈；hover 样式限定 enabled 状态。
- 输入采用 input-base 与对应聚焦样式。数值草稿失焦或 Enter 提交，Escape 恢复；输入消费 Escape 时必须阻止模态同时关闭。
- 输入禁用反馈集中于 input-disabled；复合数量输入保留内部分隔与内缩焦点框，避免重复边框。同类图标操作使用 IconButton，加减操作使用 StepperButton。
- 数值到达边界时禁用步进按钮，调用方仍保留业务校验。

## 5. 预览交互

### 5.1 缩放焦点

缩放焦点指纸张上的关注位置，与键盘焦点不同。

| 操作                     | 规则                                                   |
| ------------------------ | ------------------------------------------------------ |
| 首次打开、适应窗口       | 整张纸水平、垂直居中                                   |
| 连续拖动滑块             | 开始时捕获视口中心对应的纸张位置，整次拖动保持同一锚点 |
| 键盘调整倍率             | 保持操作前视口中心对应的纸张位置                       |
| 进入 1:1，包括校准后进入 | 保持当前关注位置，按校准值改变倍率                     |
| 平移后缩放               | 使用平移后的视口中心作为关注位置                       |

- 缩放与位置补偿在同一绘制帧生效，不叠加追赶式缩放动画。
- 纸张小于视口时居中；边缘受可滚动范围限制。同次拖动缩小再放大应保留原锚点。
- 滑块范围 50%–300%，100% 位于轨道中点，两侧采用分段对数映射。
- 滑块 100% 是适应窗口倍率的 1 倍；物理尺寸 1:1 依赖屏幕校准，两者不能混同。
- 返回完整纸张的动作命名为“适应窗口”；倍率以紧凑等宽读数常驻显示，并提供比例含义说明，不依赖 hover 才能读取。
- 滑块整个外框可操作，拖出控件仍持续响应；缩放操作不得同时触发画布平移。

### 5.2 浮动导航

缩放与翻页共享 preview-controls，整组及组内间隙共同响应。

| 状态或设备                             | 不透明度                     |
| -------------------------------------- | ---------------------------- |
| 支持悬停的精细指针设备，闲置           | 60%                          |
| 整组悬停、键盘焦点进入、按压或滑块拖动 | 100%，拖出组外保持到拖动结束 |
| 触屏或带粗指针的混合设备               | 始终 100%，不按屏幕宽度判断  |

- 1:1 选中保留品牌色，但选中本身不强制整组常亮。
- 透明度过渡 150ms ease-out，不改变布局或命中区，不增加背景模糊。
- 禁用图标保持合成后约 30% 可见度；整组为 60% 时，图标局部补偿为 50%。
- 此弱化规则不推广到表单、错误、主要操作或模态界面。
- 标尺是非交互信息，固定 60% 不透明度且不接收指针事件，不参与悬停恢复。
- 标尺放右上角，与底部翻页及左侧缩放分开；按 1/2/5 × 10ⁿ 毫米选择刻度，横线控制在约 80px 内，标注对应实际长度。

## 6. 组件规则与复用

| 组件或区域       | 规则                                                                  |
| ---------------- | --------------------------------------------------------------------- |
| 分段选择         | 同级选项共用外框，当前项使用品牌色和 aria-pressed                     |
| 图片队列         | 第一行放拖拽、缩略图、文件名、删除；第二行放数量、排序和文件大小      |
| 上传入口         | 无图片时显示引导；已有图片时收缩为“继续添加图片”，不重复数量摘要      |
| 排序与删除       | 提供键盘可用按钮，删除在触屏上始终可发现                              |
| 生成操作         | 可用、生成中、成功和失败在同一表面表达，生成时保留取消                |
| 错误提示         | 可读且可感知；累计数量错误置于折叠区域之外                            |
| 设置浮层         | 非模态 dialog/popover，允许背景操作、外部点击关闭和 Tab 离开          |
| 编辑与校准对话框 | 模态，有遮罩、标题关联、首焦点、Tab 环回、Escape 关闭和关闭后焦点恢复 |

复用入口：IconButton（图标操作）、ActionButton（普通文字操作）、StepperButton（步进）、FieldShell（字段关联）、InlineAlert（行内提示）、useModalFocus（模态焦点）。桌面与移动端共享 LayoutFields、TextModeFields、ImageFilesSection 等业务组合。

公共组件应有至少两个真实调用点及相同的视觉和交互契约。业务解析、校验、数据与生成状态由调用方负责；变体通过有限参数表达，不在调用点叠加冲突 utility。不因 JSX 相似而合并模态与非模态、range 与自定义缩放条等不同交互。

## 7. 无障碍与浮层

状态统一的是含义与反馈强度，不要求所有控件使用相同色块：

| 状态               | 规则                                                                                      |
| ------------------ | ----------------------------------------------------------------------------------------- |
| 默认 / 未选中      | 中性表面与文字；主操作仍可使用品牌色，不能因此被当作选中                                  |
| Hover              | 仅增强可操作性，不改变选择状态；禁用时不响应                                              |
| Active             | 按下期间短暂反馈，释放后结束；不等于已选中                                                |
| Selected / Checked | 持续表达当前值，同时提供 aria-pressed 或 aria-checked；分段面板、开关轨道可以使用不同形态 |
| Focus-visible      | 独立表达键盘位置，与选中或悬停可以同时存在                                                |
| Disabled           | 原生禁用并可视觉识别，保留可读性；透明度按图标、文字和内容区区分，不机械统一一个数值      |

危险操作保留危险色，成功/失败属于结果状态，可取消的生成中仍属于可操作状态。统一优先通过既有公共组件与语义 token 实现。

分段选择、纸张选项与开关共享 choice-feedback 的按压及禁用反馈，保留各自选中表面；禁用 fieldset 中的控件也必须显示禁用状态。

- 图标按钮必须有可翻译名称，装饰图标对辅助技术隐藏；关键操作可通过键盘和触摸发现与执行。
- 键盘焦点使用 2px 品牌色轮廓、2px 偏移，或等价输入聚焦样式；不得无替代地隐藏轮廓。
- 错误采用 role="alert"，字段关联 aria-describedby、aria-invalid；进度提供可访问状态播报。
- 滑块提供范围和当前值；开关使用 switch，分段选择使用 group 与 aria-pressed。
- 自定义 range 在 WebKit 与 Gecko 均提供轨道和 thumb，thumb 外径统一 16px，垂直居中。
- 真正模态使用 aria-modal="true" 并实现对应行为；设置浮层不声明模态。
- 关闭恢复焦点不得抢走用户已经移至其他控件的焦点。
- 层级遵循基础内容、预览控制、对话框、浮层内子菜单、更新提示的职责；考虑祖先层叠上下文，不能凭更大的 z-index 覆盖模态关键操作。

## 8. 动效与文案

| 场景                | 动效                                                 |
| ------------------- | ---------------------------------------------------- |
| 输入边框、按钮颜色  | 约 150ms，仅过渡明确属性                             |
| 预览导航透明度      | 150ms ease-out                                       |
| Toast、抽屉、对话框 | 180ms ease-out，可透明度/位移/轻微缩放，不动画化高度 |
| 列表进入            | 150ms ease-out                                       |
| 生成状态与进度      | 200ms 或线性进度                                     |
| 主题切换            | 约 300ms，仅颜色相关属性                             |

- 不使用 transition-all，不给高频操作增加明显弹跳；CSS 与 Framer Motion 均遵守 reduced-motion。
- 文案短而明确，优先描述操作，不重复已可见的信息。
- 中英文、aria-label、title、提示与状态统一进入 translations.ts；同一动作使用同一翻译 key。
- 数量和单位通过格式化或翻译参数表达；中文标题不使用英文大写式宽字距。
- 长文案不能因截断丢失动作含义。

## 9. 验收原则

- 按影响检查键盘、触摸、亮暗主题、中英文、长文件名与边界状态。
- 响应式基准：1280×720、1440×420、1023/1024px 切换、375×667、320px 内容宽度。
- 视觉判断结合实际操作，尺寸与命中区用浏览器测量；class 断言不等于实际可用。
- 代码改动按风险运行格式、lint、相关测试和构建；纯文档检查格式、链接、事实与范围。
- 测试结果、设备覆盖、未完成项和候选重构统一记录在 [UI 维护记录](UI_MAINTENANCE.md)。
