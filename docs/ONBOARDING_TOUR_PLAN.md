# LabelPilot 箭头导览方案

日期：2026-10-19

用直接指向工作台控件的操作导览替换快速设置。保留空白预览区的上传/编号入口、设置记忆和使用指南，帮助用户在真实界面中完成第一张标签。

## 步骤

| 平台 | 顺序                                                   | 指引内容                                                       |
| ---- | ------------------------------------------------------ | -------------------------------------------------------------- |
| 桌面 | 添加内容 → 调整排版 → 检查预览 → 缩放与 1:1 → 生成 PDF | 根据当前模式介绍内容控件、行列与份数、预览、屏幕校准和下载打印 |
| 手机 | 编辑入口 → 添加内容 → 调整排版 → 检查预览 → 生成 PDF   | 内容与排版步骤展开编辑面板并滚动到目标；预览与生成步骤回到纸张 |

每步展示一个高亮目标和一两句说明，普通目标配有箭头；提供进度、上一步、下一步/完成、跳过和关闭。用户可以直接操作实际控件，导览文案随当前模式更新。导览不会自动生成 PDF。

桌面“缩放与 1:1”步骤指向实际的 1:1 按钮，解释适应窗口的 100% 与物理实际尺寸、Ctrl+0 后用直尺测量校准，以及屏幕校准与 PDF/打印缩放的区别。首次点击按钮时收起导览并进入现有校准窗口；已有有效校准时直接切换实际尺寸显示。该步骤切换到手机布局时回退至预览步骤，避免指向隐藏按钮。

## 启动与退出

- 无保存设置、无已读记录的新用户首次自动进入；已保存过设置或处理过旧快速设置的用户继续进入工作台。
- 完成、跳过、关闭或未被输入控件消费的 Escape 后记住已处理状态；打开使用指南、进入校准窗口或直接生成 PDF 属于中断，不写入已读标记。已有已读记录不覆盖。存储不可用时保留手动入口，并避免反复自动提示。
- 使用指南提供“重新导览”，生成 PDF 时禁用启动导览。
- 自动进入和手动重放均记录启动时编辑面板开合/高度和有效焦点。自动进入时面板初态为关闭，导览步骤或编辑入口打开的面板在退出时恢复关闭；手动重放恢复启动时的面板状态。用户实际修改的参数和上传内容继续保留，主动转移到其它有效控件的焦点不被抢回；打开指南或校准时由新窗口管理焦点。
- 视口跨越桌面断点时按同一语义步骤重新定位；目标暂时不可见时等待挂载并重新测量，避免留下无法操作的遮罩。

## 视觉与可访问性

- 沿用工作台主题、字体和按钮。遮罩与高亮不拦截真实控件的操作；桌面说明框优先放在预览空白区域，避让整个控制面板、浮动缩放和标尺。普通目标的箭头保留可辨识长度，尖端落在经滚动容器和视口裁剪后的目标内部；重叠的小目标优先连接最近且可辨识的外露边缘。可见目标面积超过视口一半且与卡片重叠时，仅保留高亮，不绘制横穿纸张的箭头；目标缺失时保留可操作的退出提示。
- 桌面为非模态提示，保留工作台键盘操作；手机内容和排版步骤将卡片放进编辑面板底部的独立槽位，与滚动表单共同占用面板高度，保留面板头部操作。横屏短视口按需增高面板，给实际表单保留空间；卡片正文独立滚动。SVG 高亮和箭头使用视口坐标，目标不可见时仍以卡片实际位置开孔，手机仍处于同一模态焦点范围。
- 说明框通过标题/正文关联，使用独立的 polite/atomic 状态区域播报当前进度、标题和正文，步骤切换后焦点保持可达。
- 使用稳定的语义目标标记，选择当前实际可见的响应式实例；滚动、尺寸变化和模式变化后更新定位。
- 支持中英文、明暗主题、360px 手机和短视口；交互目标至少 44px，支持减少动效偏好。
- 导览激活时暂缓空白页 QuickStart；退出后满足空白、有效排版和适应窗口条件时恢复入口。QuickStart 显示时标尺和缩放组一起隐藏，使用对称间距，不为浮动控件写死避让尺寸。

- 删除快速设置组件、配置草稿/原子替换/撤销 API 和专用测试，保留已有持久化格式及用户设置。
- 更新测试场景的已读标记、使用指南、README 和 UI 规范。
- 回归覆盖首次/回访/存储异常、跳过/完成/重放、模式与参数不被导览改变、真实控件可操作、手机面板和焦点、断点切换、目标缺失、定位边界。
- 运行类型、单元测试、代码/格式、生产构建/离线缓存检查，以及已有桌面/手机浏览器回归；在生产预览中检查真实高亮、箭头和状态恢复。
- `e2e/guided-tour.spec.ts` 使用真实首访状态，守护 1280×720 明暗、1440×420 短屏、390/360px 手机及 844×390 手机横屏的卡片避让、箭头、真实表单操作、中断恢复与动态设置菜单。其它工作台回归继续预置已读标记。
